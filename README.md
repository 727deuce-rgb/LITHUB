# LITHUB

A polished Next.js MVP for a hybrid AI product workspace, community, and monetization platform.

## Stack
- Next.js
- React
- TypeScript
- Lucide React

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production deployment

This app is prepared for a Vercel deployment. To publish live:

1. Push this repo to GitHub
2. Import the repository in Vercel
3. Use the default Next.js settings
4. Deploy

## Notes
- This is a production-style MVP with production copy and content structure.
- It is intentionally light and front-end focused to avoid unnecessary complexity before the first live publish.
